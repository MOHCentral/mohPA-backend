## 2026-10-08 - Fixed Hardcoded Secrets in Config files\n**Vulnerability:** The `packages/api-service/src/server.ts` and `packages/fesl-engine/src/config/config.ts` used hardcoded values as fallbacks for `JWT_SECRET` and `INTERNAL_API_KEY` if environment variables weren't defined.\n**Learning:** This allowed the application to start up with predictable credentials if the administrator forgot to set the environment variables properly.\n**Prevention:** Fail securely by explicitly throwing an Error if these critical environment variables are absent, enforcing their configuration (except for 'test' environments).
